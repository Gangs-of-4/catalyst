# 21st.dev (Magic MCP)

## Purpose

Gives Claude Code a library of UI components and patterns (forms, cards, nav, dialogs, empty states) to use as a design reference.

## Capabilities

Searches 21st.dev's community component library and returns examples or generated component code. The code is React + Tailwind (shadcn/ui style). VERIFY the exact tool list after install with `/mcp`.

## Why This Project Uses It

To give the Phase 2 redesign (phase2-plan M8) better UI/UX patterns. It is **reference only**. ADR-0035 and phase2-plan §6 keep the frontend as static HTML, CSS and JS with no framework, so:

- Never paste React, JSX or Tailwind classes into `frontend/`.
- Rewrite any pattern you take from it by hand in plain HTML, using the tokens in `frontend/static/app.css` and the shared components in `common.js`.
- `frontend/DESIGN.md` stays the source of truth for the look. 21st.dev output is an input to it, not an override.

## Installation

Each member installs it on their own machine, at **local scope** (private to you, stored in `~/.claude.json`, never in the repo):

```bash
claude mcp add --transport http 21st https://21st.dev/api/mcp --header "x-api-key: <YOUR_21ST_API_KEY>"
```

Then restart Claude Code so the tools load. Check it with `claude mcp get 21st` (it should say Connected).

Don't use `--scope project`. That writes `.mcp.json` into the repo, and the repo is public.

## Configuration

- Transport: HTTP
- URL: `https://21st.dev/api/mcp`
- Auth header: `x-api-key`

See `mcp/config/config.md`.

## Environment Variables

None in the repo. The API key lives only in each member's local Claude Code config (`~/.claude.json`). Get your own key from your 21st.dev account (VERIFY where the dashboard lists it).

## Tools Available

VERIFY after install (`/mcp` lists them). Expect component search, inspiration and generation tools.

## Usage Guidelines

- Use it while designing a component or page in M8. Pick a pattern, then rebuild it in plain CSS and JS.
- Check every result against `frontend/DESIGN.md`: AA contrast, 360px width, keyboard focus, Hindi (Devanagari) text.
- No Cal.com or other brand names or marks in what we ship (phase2-plan §6).

## Security Considerations

- The key is personal. Never commit it, put it in a doc, or paste it into a PR or issue. If one leaks, rotate it in the 21st.dev dashboard.
- It is read-only from our side: it returns code, it doesn't touch the repo or our backend. Don't send it personal data (patient or owner details). Send only UI descriptions.
